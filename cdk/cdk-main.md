# Overview

The Nucleus Cell Development Kit (CDK) is a Python library for analyzing synthetic cell experiments. It reads instrument output — microscopy or plate reader — into a DataFrame and gives you population statistics, curve fits, and plots.

## Install

```bash
pip install nucleus-cdk
```

See [Installation](./install.md) for Python version requirements and the JupyterHub route.
