# Overview

Driving a discovery-plate experiment from an `experiment.toml` config to a per-well
pipetting plan: the DOE generators, the base master-mix solver, and the output files the
liquid handler consumes.

The configuration format is documented in full at
[The `experiment.toml` file](./experiment-toml.md).
