Reading the edges

What each connection is actually backed by in the docs.

Solid arrow — confirmed composition (points from constituent into what contains it)
Bold arrow — only known to co-occur inside a documented implementation
Dotted arrow — requirement, substitution, or indirect readout — not a build dependency

Cx43 needs a bilayer

membrane-pore-cx43/spec.md states it "cannot be functionally deployed in Nucleus Cytosol alone" — it needs the POPC/Chol membrane for pore assembly. Same constraint applies to α-Hemolysin.

α-Hemolysin → Cx43 is a stated substitution

The α-Hemolysin spec names Cx43 as "a functionally comparable alternative" without the BSL-2 handling requirement, and flags itself as not actively supported.

tetR-aTc + IV-HSL only met in one page

Nothing in either module's own spec links them. They appear together only in implementations/responder-atc-ivhsl/main.md, which cites both specs directly.

ClpXP's readout is borrowed

ClpXP's own reaction tables run on purified deGFP-ssrA as the degradation reporter — it doesn't compose deGFP as a module, it consumes it as an assay reagent.

LacI-IPTG isn't in the index yet

It has a full spec.md but doesn't appear in either table in modules-main.md.

PPK stands alone

Energy/PPK is listed in the PURExpress table but its spec makes no cross-reference to any other module — no composition or substitution claim found.
