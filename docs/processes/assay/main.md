# Overview

An assay reads something and yields a value. That is what separates it from the other roots: nothing it produces goes back into a tube. Where the reading costs the sample, that is also where a chain of work stops. Where it does not, the chain carries on around the reading.

What it yields is an observation, which may be quantitative or qualitative. A measurement is the quantitative case.

Its instances are the readouts this corpus runs: a color read, a total-protein quantitation, a gel, an image, and an osmolality.

# Protocol

None. Every step is on an instance page, because what is being read decides how it is read.

# Processes

- [Colorimetric Readout](../colorimetric-readout/main.md) — the stage every sensing cascade ends at. Two routes, a plate-reader absorbance read and an endpoint visual score, so the general case is what it yields.
- [Pierce660 Assay](../pierce660/main.md) — a standard curve, a linear fit, and a concentration calculated from it. One of the two instances that narrow to a measurement.
- [Protein Gel](../protein-gel/main.md) — bands read by eye, with a gel imager available to semi-quantitate them.
- [Microscopy Readout](../microscopy-readout/main.md) — one object at a time, read by eye from an image. It resolves single objects, so it can say which population a signal came from and how much of it still holds the label.
- [Osmometry Readout](../osmometry-readout/main.md) — one osmolality per solution, read from a spent aliquot. The other instance that narrows to a measurement. It reads a solution and never the lumen of a cell.
