# Nucleus Hub Is Decommissioned

Nucleus Hub, the hosted JupyterHub environment for the Cell Development Kit (CDK), is no longer available.

## Analyze Data with the CDK

Install the CDK on your own computer. See the [CDK installation guide](../../cdk/install.md) for setup steps. The CDK is open source. The Nucleus team welcomes contributions to it.

## Write a DevNote

Nucleus Hub previously served as the writing environment for DevNotes. To write a DevNote now, contact the Nucleus team at build@bnext.bio.
