# Nucleus Hub Is Offline

Nucleus Hub, the hosted JupyterHub environment for the Cell Development Kit (CDK) and Developer Notes (DevNotes), is offline. Stay tuned. The team will build new tools for easier contributions to Nucleus.

## Analyze Data with the CDK

In the meantime, the CDK is [here](https://pypi.org/project/nucleus-cdk/). Install it on your own computer. See the [CDK installation guide](../../cdk/install.md) for setup steps. The CDK is open source. The Nucleus team welcomes contributions to it.

## Write a DevNote

Want to write a DevNote? Contact the Nucleus team at build@bnext.bio.

For reference, the original Nucleus Hub walkthrough is still here: [Nucleus Hub (Archived Tutorial)](./nucleus-hub-dep.md).
