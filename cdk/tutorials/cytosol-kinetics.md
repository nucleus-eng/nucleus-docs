# Overview

This page will cover loading a kinetic plate reader run, subtracting a blank, normalizing to a standard, and fitting steady state and rate. It is the cytosol counterpart to [Analyzing Microscopy Data](./cell-microscopy.md).

In the meantime, the existing [Cytosol Kinetics Analysis tutorial](../../guides/platereader_tutorial.md) covers this workflow, and the notebook templates shipped with the package (`notebooks/templates/kinetics_tutorial.ipynb`) run the same analysis with commentary.

Reference material is in the [cytosol API reference](../api/cytosol.md).
